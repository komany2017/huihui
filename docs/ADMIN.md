# 润泉养元 · 管理后台使用手册

访问地址：`http://localhost:3000/admin/`（局域网内其他设备用 `http://<服务器IP>:3000/admin/`）
默认账号：`admin` / `admin123`（可用环境变量 `ADMIN_USER` / `ADMIN_PASS` 修改）

---

## 1. 登录与退出

- 输入账号密码登录，登录态保存在浏览器 localStorage
- 服务重启后登录态失效，重新登录即可
- 点击左下角「退出登录」可主动退出

## 2. 数据概览

显示核心运营指标：用户数、预约订单、商品订单、健康档案、体质报告，以及服务/商品/疾病/穴位的内容数量。

## 3. 内容管理（服务 / 商品 / 疾病 / 穴位）

四个模块操作方式完全一致：

- **搜索**：顶部输入框按名称/ID 实时过滤
- **新增**：点击「+ 新增」，填写表单保存
- **编辑**：点击行内「编辑」，修改后保存
- **删除**：点击「删除」并确认（不可恢复）

表单字段说明：

- 简单文本/数字字段直接输入；「是/否」下拉对应布尔值
- 列表/对象类字段（如功效列表、服务流程、规格列表）按 **JSON 格式** 编辑，保存时自动校验
- `id` 为唯一标识，创建后不可修改
- 图片字段填图片 URL（支持任意可访问的图片地址）

**改动何时对小程序生效？** 小程序**下次启动**时自动拉取最新目录数据覆盖；已在运行中的页面不主动刷新。

## 4. 预约订单 / 商品订单

- 自动按创建时间倒序列出**全部用户**的订单
- 行尾下拉框可直接修改订单状态：
  - 预约订单：待确认 → 已确认 → 已完成 / 已取消
  - 商品订单：待付款 / 已付款 / 已发货 / 已完成 / 已取消
- 状态修改实时保存到服务器；用户在小程序「订单列表/详情」中同步可见

## 5. 用户与档案

- 列出全部设备用户：昵称、性别、年龄、联系方式、四类数据数量
- 点击「查看详情」弹窗展示：
  - **基本档案**：用户在小程序「我的」中填写的个人资料
  - **订单记录**：该用户的预约与商品订单
  - **健康档案**：病情/调理/诊疗记录
  - **体质报告**：测试时间、主要体质、九种体质得分
- 用户数据以 `deviceId`（设备号）区分，同一设备的数据自动归集

## 6. 基础配置

JSON 编辑器整体保存（格式错误会拒绝保存）：

| 配置项 | 说明 |
|---|---|
| 预约时段 | 字符串数组，如 `["09:00-10:00", ...]`，小程序预约页按时段展示 |
| 热门疾病 | 字符串数组，疾病搜索页的热门标签 |
| 服务分类 / 商品分类 / 疾病分类 | `{id, name}[]`，各列表页的顶部分类 tab（保留 `all/全部` 项） |

## 7. 数据存储与备份

- 全部业务数据保存在 `server/data/db.json`（可用环境变量 `DATA_DIR` 更换目录），原子写入，服务重启不丢失
- **备份**：拷贝 `db.json` 即可；**恢复**：停服后用备份文件覆盖再启动
- **重置演示数据**：删除 `db.json` 后重启服务，自动重新播种
- **迁移**：把整个 `server/` 目录复制到新机器，`node server/index.js` 即可运行
- 首次启动会自动播种内置演示数据；已有数据时不会重复播种
- 启动日志会打印当前数据文件的完整路径，便于确认

## 8. 常见问题

| 问题 | 处理 |
|---|---|
| 小程序里没看到后台改的内容 | 小程序需重启（重新打开）才会拉取新目录数据 |
| 登录提示 401 | 服务重启导致 token 失效，重新登录 |
| 保存 JSON 字段报错 | 检查 JSON 格式（引号、逗号、方括号配对） |
| 真机无法访问接口 | 确认手机与服务器在同一局域网，且小程序 `API_BASE_URL` 已改为服务器局域网 IP |
| 忘记管理员密码 | 用环境变量 `ADMIN_USER`/`ADMIN_PASS` 重启服务覆盖 |
| 数据是否安全 | 当前为演示级实现（HTTP 明文 + 简单口令），生产环境请启用 HTTPS、强口令并限制访问来源 |
